# A3 双参照跨物种检验：冻结执行协议

冻结时间：2026-10-08；新推断运行前写入。现有集合先前已经查看，本分析属于事后补充对照。家族为 `A3-cross-species`，四个有效 p 值（两 PAS × 两检验）交由根 agent 统一 BH。

1. 现稿来源是 contract-r2/polyApipe（128 人、222 鼠）；APADETECT 点过滤加 p50 是替代 PAS 验证。输入取两套封存 supplement/tables；polyApipe 与 contract-r2 对应输入须核对 SHA。使用 `supported50_p08`，阈值固定 0.02，保持原有 P–M 复现及双参照集合。不得按结果重新筛集合。
2. 背景为封存 Ensembl release 116 的一对一 ortholog 中，人类 GSE118258 和小鼠 CIP、WOT 均有完整、同贡献者 P/M/S 三联体且有有限 `P_DWUI/M_DWUI/S_DWUI` 的基因对。用 gene ID 映射，不用符号近似。对所有背景基因读取 `matched_pms/matched_state_vectors.tsv.gz`，不将只含复现候选的导出误作全背景。两 PAS 沿用同一资格定义，各自测量背景不同；报告共同测量背景描述计数，不另择有利背景推断。
3. 每物种背景基因标记为 0/近端(-1)/远端(+1)：只有原有 `candidate_screen/dual_reference_candidates.tsv` 成员才非零。核对候选方向在每条规定路线中 P–S、P–M 均达到原阈值。全集之外的候选保留在流失表中，不能计入推断分子。
4. reference-capacity 分层由该物种同贡献者参考值计算。层键为 S 与 M 各自可容纳近端变化的路线数（参考≥0.02）、各自可容纳远端变化的路线数（参考≤0.98）、所有 S/M 路线参考值中位数的五分位、各路线 PAS 数中位数的三分位。各物种独立建立分位点，仅用全集，不使用结局分层。层内原样保留近端、远端、非成员数量；零容量层不得出现相应方向事件。报告层大小、事件固定比例、方向固定比例与背景资格。
5. 重叠富集：统计两集合共同成员数 K。两个物种各自在层内独立洗牌三类标签，20,000 次；上尾 p=(1+K_null≥K_obs次数)/(B+1)。分析期望由两个物种层内成员概率乘积求和核对 Monte Carlo 均值。此检验只检验成员共享，方向比例在洗牌中完整保留。
6. 方向一致性：固定两个原有集合的成员位置和实际共同成员，对每物种仅在该物种的“层内已选成员”之间洗牌近端/远端方向。统计共同成员同向数 T；独立 20,000 次，上尾 p 同上。这样方向检验不把共同成员数量富集当方向保守性。未入背景、无共同成员或全固定须明确记录，不能据阴性推导物种特异。
7. 功效曲线：每 PAS、每检验独立模拟 3,000 次/备择 OR={1,1.5,2,3,4,6,8,12,16,32}，种子由固定主种子 20261008 和 source/test/effect 生成。重叠备择先洗牌人类标签，再在每鼠层中以 Fisher 非中心超几何抽取鼠成员，相对人类成员抽取权重 OR，保留各层鼠集合规模，再随机分配原近/远数量。方向备择固定成员，先层内洗牌人方向，后对鼠层内固定数量近端标签赋权：在人类近端共同成员处 OR、在人类远端共同成员处 1/OR、非共同成员处 1；等价以 OR^T 倾斜同向数的条件分布。保留背景分层与层内集合规模、方向比例。
8. 用独立功效模拟相对封存零分布计算 p，报告 alpha=0.05 和 0.0125（四检验 Bonferroni 保守界，最终 BH 由根 agent 执行）的拒绝率、二项 95% 区间、模拟期望效应。可检测效应定义为指定网格上首次达到 80% 功效的 OR 与相应期望共享数/同向率；若 OR=32 尚未达到，写“网格内未达到”。OR=1 为独立尺寸校准；同时报告有限零分布可达到的最小 p 和集合/分层的最大可变范围。
9. 输出完整背景标记、共同成员、背景及集合流失、分层诊断、原始 p、功效曲线/可检测效应、随机种子、输入与脚本 SHA、运行日志、中文论点边界。不修改正文、旧结果或旧脚本。

## 功效诊断补充（首轮之后；保留原定模型）

首轮代码复核发现，方向备择的顺序注入仅能改变鼠层内方向；若鼠共同成员的方向在层内完全固定，该 OR 无法改变人方向，即使人方向尚可变。这不是检验 p 值错误，但原功效结论只覆盖这个较窄的备择。保留全部原功效曲线与原始 p，不选择替代检验。另以固定共同成员和两物种层内方向数量，组合枚举共同成员每一种可能方向配置，构造精确零分布。以精确零分布乘 `OR^T` 并归一化作为“双方联合方向倾斜”的功效诊断；这是首轮后的敏感性而非先验主功效模型，须同时报告。网格、次数、alpha 和 80% 定义沿用原约定。用此独立组合枚举同时核验原方向零模型的期望、支持范围与可达到的最小离散 p，禁止把 `1/(B+1)` 蒙特卡洛分辨率误作此离散检验真实可达到的最小尾概率。
