# 全基因净位移 vs 严格复现局部区间（描述性，2026-10-08）

脚本：`compute.py <bundle tables> <out>`。输入：`candidate_screen/recurrent_region_pairs.tsv.gz`（recurrent_strict=True，按区间对去重）、`endpoints/route_effects.tsv.gz`（setting=supported50_p08，即正文 ΔDWUI；*Riok3* P–M = +0.0247/−0.0132 与正文一致）、`union_pool/figure5_union_claims.tsv`（入池路径）。
局部方向 = 区间包含率变化符号（ΔI<0 = 区间丢失，预期 ΔDWUI<0）。每个基因在两研究的全基因 ΔDWUI 分为：两研究同号且均 ≥0.02（被 DWUI 复现捕获）/ 同号但至少一研究 <0.02 / 符号相反。无零模型，不做检验。

小鼠 P–M 共 246 个严格区间基因，124 个缺至少一个研究的全基因估计（105 个缺 Schiebinger2019–2i 的同库 P–M 估计），不计入分母。

小鼠 P–M 符号相反的 5 个基因：*Riok3*（−0.156 对 +0.025/−0.013）、*Rbm39*（−0.112 对 +0.017/−0.042）、*Fxr1*（+0.161 对 −0.019/−0.020）、*Fgfr1op2*（−0.279 对 +0.033/+0.024）、*Tmem183a*（−0.175 对 +0.071/+0.031）。*Fgfr1op2*、*Tmem183a* 在两研究中都反号且幅度不小，但未做家族内/外分解，也未在 p50 中出现，使用前需核对。

## 边界
- union pool 大部分按 |ΔDWUI|≥0.01 入池（小鼠 P–M 246 个中 236 个），因此样本偏向被 DWUI 捕获；局部变化存在、但 DWUI 与 MPRO 都未达入池标准的基因从未进入分析。20.5% 应写为"在本候选池中"的比例，很可能低估。
- 与低净位移筛选（51 个中 8 个）互补：筛选是从 DWUI 很小的基因出发找局部变化；这里是从复现局部变化出发看 DWUI 是否捕获。
- 事后描述性分析，需列入局限中的事后分析清单。
