# 冻结协议方法复核

2026-10-10。根协议已消除预审中的开放选择；按现冻结协议执行独立数值审查。方法层准备通过，生产结果尚未回放，不表示共享结论通过。

三定义固定原 P、主 marker/setting、`unique_support/common_M_bridge` 和共同 728 对背景；本审查已从旧 751 与实际桥接贡献身份独立重建 735（仅人共同资格）及 728（两物种共同资格），原 27 中可测 25、不可测 2。D00/D01 的贡献库、层级权重、PAS IDs 逐项相同。研究与系列范围为原五路线，不加入 Guan。

九阈值研究票仍要求所有可测 series 均过同一方向阈值，至少两 study 同向，允许第三 study 反向。缺测不是 neutral；新三定义的类别必须全部重建。固定理论 0..1 容量为与旧模型相同的可行性控制，实际 retained 端点仅 QC；不能声称该容量已经完全匹配全部 retained-PAS 可用范围。reference baseline 随 M/M* 更新。

full 模型现在明确要求实际合格 MC 的目标基因整数 GEX 聚合 CPM、APA depth/nMC、对应 reference baseline，而非旧技术 proxy。GEX numerator、全基因 denominator、MC 身份及 source hash 必须可追溯；本地 marker-only 矩阵不足以独立提供这些 GEX。独立 QA 将重算 group→pair→library-weighted route→study median→跨study gene-feature median 和固定 qcut bins。

每定义/阈值/model 独立物种内固定三类边际，100,000 次 fresh numerical null；按冻结 seed 参数重算。独立解析期望、upper-tail 与可移动性均须回放。0 SD 的 planned formal 项按不可推断标识，校正用 p=1 保留，不把它解释成否定共享的生物学证据。

原 P–S 校准保留观察、期望、raw p、100,000 draw 数组；其校正 q 进入新家族重算，不应复制旧 q。新家族的计数：

| 家族 | 固定大小 |
|---|---:|
| 每 definition×threshold×model：P–M/P–S 各四个 recurrent 格 | 8 |
| 每 definition×model：九 threshold | 72 |
| 每 definition：两 model | 144 |
| 全 unique：三 definition 的 P–M 216 项 + P–S 72 项只一次 | 288 |

每个完整 3×3 的五个 nonrecurrent 格只描述，不能误进 formal BH。三定义之间共享校准或同一观测模块，不是独立实验重复。主判断为 human_Mstar/full/q72；coarse、q144/q288、both_Mstar 完整报告，不择最小 q。旧 27 的资格损失与新方向变化须分开；新成员必须从固定 728 的 labels 重建。

后续独立验收会覆盖实际 GEX、贡献/轴 identity、study collapse、bin/strata、观察数、解析期望、数值 draw replay、MC precision、所有 family 和零移动性解释。固定 728 是旧背景中的共同覆盖子集，本身不能证明 M 跨研究等价或多能性特异，也不能用与旧 q 的差异声称新共享显著增强。
