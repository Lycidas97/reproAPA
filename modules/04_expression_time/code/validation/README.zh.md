# 七项分析的实际运行入口

服务端运行目录：`/root/nfsdata/apadetect/analysis_projects/reproapa_integration_validation_20260913/execution_v1`。

`bootstrap.py` 冻结细胞顺序并核对 161 个原始计数文件；`launch.py` 将明确指定的分析入口作为独立进程启动，保存 PID、脚本 SHA256、日志和重试历史。每项作业限制为 2 个数值计算线程、低 CPU/I/O 优先级；当前最多 7 个入口，等待依赖时不做计算。未创建 Codex 定时自动化，也不发送外部消息。

| 入口 | 本批实际运行的计算 | 自动依赖 |
|---|---|---|
| `a01_quality.py` | 21,615 个分层 query 对完整 551,201 参考细胞，比较 joint scVI30D、二维图、未校正 PCA30 的精确 kNN（k=15/30/50） | PCA 等待 A03 全基因计数；已完成的两种表示不重跑 |
| `a02_graphs.py` | 先回读联合图和 native 三层图；5 个权重/去时间/去跨物种图、18 次全细胞 UMAP（含 3 种子及原/随机初始化） | 独立运行，不使用新注释选择参数 |
| `a03_features.py` | 161 文库原始整数 counts、完整可用一对一基因、对称特征和留出特征；训练队列为 4 个试跑及 12 个全量模型 | `a03_train_queue.py` 仅在设备显存占用 <1 GiB 且利用率 <10%、连续两次确认时运行 `train_one.py` |
| `a04_annotation.py` | 留出基因的逐文库状态表达、物种内留一研究与跨物种双向 Spearman 识别、逐家族 AUROC | 等待 A03 的特征冻结；检测资格只从各折训练研究确定 |
| `a05_apa.py` | 固定 1,194/1,569 候选全集，逐对比、逐研究删一分析及原效应/方向回读 | 本阶段使用既有 route effects；细胞级重聚合另为后续阶段 |
| `a06_doublets.py` | automatic calls、最高 5%/10% 三种排除及 60 个文库×UMI 十分位匹配随机对照；UMI 调整后状态分数比较 | 独立运行，产物供 A04/A05 后续分析 |
| `a07_partitions.py` | 11 个原图、基线重放及邻近分辨率×3 种子，共 110 次 Leiden；WOT 使用原 kNN 缓存重构 k30 图 | 独立运行，保留逐细胞替代 membership |

主计划没有缩减。上表为本批已实现并提交的执行阶段，`STAGE_COMPLETE` 不代表整项分析完成。后续还包括：正式批次/生物保持指标、A02 expression-only 图和时间置换后 OT 重拟合、WOT 同细胞统一 chooseR 流程、注释冲突与证据层级审查，以及使用替代标签/分区/排除掩码的细胞级 APA 重聚合。这些步骤尚未全部接入自动执行，不把当前进程提交等同于所有后续计算均已排队。

原始模型和主图谱不被改写。输出在各 `A0x/` 目录。`status_snapshot.py` 检查当前 PID 与命令，区分运行、等待上游、等待 GPU、阶段完成及失败；进程消失不自动当作完成。

2026-09-14 A03 抽样修正：原 `shared/pilot_indices.npy` 只按物种和研究等额抽样，与 A03 原计划的时间/条件平衡要求不符。模型仍未开始训练时，`prepare_balanced_training_pilot.py` 生成独立的 `A03/pilot_balance_v2/`，训练器现引用该版本；队列启动时会准备或核验该输入。新样本在研究内进一步按注册的路线、采样标签、实验条件和文库分配名额，共 60,000 细胞、161 文库。119 处分层名额通过独立水位分配法核对，原 R5 所用旧样本及哈希保持不变。更新训练器时仅短暂暂停并恢复本项目空等 GPU 的队列，确认没有训练子进程；旧运行脚本和替换哈希在 `A03/pilot_balance_v2/before_runtime/` 与 `runtime_update.json` 保留。

A04 的识别实现是基于留出基因的 Spearman 表达相似性；文库先等权，再在研究内合并状态得分、研究间等权汇总家族得分。它不是正式 MetaNeighbor 软件的复现，不据标签一致性或 AUROC 单独授予同源身份。独立性限于特征留出及训练/测试研究分离，不是新的独立实验。
